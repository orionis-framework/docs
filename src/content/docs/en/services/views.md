View renders server-side HTML with async Jinja2 and returns an Orionis response.

## Learning path

1. [Rendering pages](/en/services/views/rendering-templates): context, pending renders, responses, and forms.
2. [Layouts and helpers](/en/services/views/template-language): Jinja, links, sessions, translation, and escaping.
3. [Configuration and extensions](/en/services/views/configuration-and-extensions): loaders, caches, providers, and diagnostics.

Requires Python 3.14+ and the Jinja2/MarkupSafe/Markdown/msgspec dependencies declared by the project. The facade needs a booted application; isolated-engine examples are useful for tests and extensions.
